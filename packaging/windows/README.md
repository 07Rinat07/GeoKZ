# Windows packaging placeholder

Эта директория будет использоваться после появления PySide6-клиента.

Предполагаемый процесс:

1. собрать desktop-клиент в `dist/GeoKZ/`;
2. добавить локальный backend или launcher;
3. подписать исполняемые файлы;
4. собрать установщик из `GeoKZ.iss.example`;
5. проверить чистую установку на Windows 10 и Windows 11.
