# GeoKZ — руководство пользователя (RU)

Версия: `0.2-dev`.

## Назначение
GeoKZ объединяет геологическую информацию по территории, месторождению, структуре и скважине из собственной базы и разрешённых внешних источников.

Основной путь: территория или координата → месторождения/структуры/скважины/сейсмика → паспорт объекта → паспорт скважины → интервалы, литология, ГИС, керн, испытания, нефть/газ/вода → источник и доказательство.

## Языки
Интерфейс, справочники, названия и пользовательская документация поддерживаются на русском, казахском и английском.

## Поиск по координатам
Географический ввод: `43.652341 / 51.168420`. Запятая также принимается.

Проекционный ввод: `X=5085125.325`, `Y=711157.665`. Также принимается `5085125,325 / 711157,665`.

Для больших X/Y необходимо указать исходную систему координат: EPSG, UTM-зону, СК-42/Гаусса–Крюгера либо настроенную локальную CRS. GeoKZ не должен угадывать CRS только по числам.

## Паспорт скважины
Содержит координаты, тип/оператора/статус, даты, глубину, траекторию MD/TVD/TVDSS, интервалы, стратиграфию, литологию, нефть/газ/воду, пористость/проницаемость, ГИС/каротаж, испытания, дебиты, давление/температуру, керн/образцы и связанные документы.

## Корреляция разрезов соседних скважин
Выберите опорную скважину и соседние скважины. GeoKZ формирует сопоставление разрезов в двух видах:

- визуально: вертикальные колонки скважин, литологические интервалы, коллекторы, нефть/газ/вода и линии одинаковых реперов;
- текстом: глубины реперов, разница отметок, различия мощности интервалов, литологии, свойств коллектора и результатов испытаний.

Для сопоставления предпочтительно используется TVDSS. Если доступны только несовместимые системы глубин, GeoKZ предупреждает пользователя и не рисует автоматическую ложную корреляцию.

Репер хранится отдельно с кодом, названием, глубиной, методом интерпретации, источником, достоверностью и статусом проверки. Корреляционная линия должна открывать первичный источник или данные ГИС, на которых основана интерпретация.

## Источники и обновление
Для значимых данных доступны происхождение и статус проверки. Внешние данные не перезаписывают проверенные значения автоматически. GeoKZ поддерживает ручное и периодическое обновление, а без интернета локальная база продолжает работать.

## Подсказки и помощники
Для сложных полей используются короткая подсказка, расширенное объяснение, пошаговый мастер и диагностическое предупреждение.
