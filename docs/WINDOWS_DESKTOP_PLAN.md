# План Windows-приложения GeoKZ

## Главный принцип

Конечному пользователю не потребуется Docker, Python или командная строка.
Текущий Docker Compose предназначен для разработки и серверной установки.

## Выбранное направление

Интерфейс: **PySide6 (Qt for Python)**.

Причины:

- остаёмся в Python;
- полноценные таблицы, формы, деревья и GIS-виджеты;
- нормальная работа с большими локальными наборами данных;
- сборка `.exe`;
- возможность встроить карту через Qt WebEngine либо отдельный GIS-компонент.

## Режимы эксплуатации

### 1. Локальный автономный режим

```text
GeoKZ.exe
├── локальный FastAPI-процесс на 127.0.0.1
└── локальная служба PostgreSQL/PostGIS
```

Установщик:

- устанавливает приложение;
- при необходимости устанавливает PostgreSQL/PostGIS;
- создаёт отдельный кластер и базу GeoKZ;
- применяет Alembic-миграции;
- создаёт службу автозапуска;
- не открывает базу наружу.

### 2. Сетевой режим

```text
GeoKZ.exe ── HTTPS ── центральный GeoKZ API ── PostgreSQL/PostGIS
```

Подходит для нескольких геологов и общей редакторской базы.

### 3. Гибридный режим

Центральная база плюс локальный read-only кэш для слабого или временно
отсутствующего интернета. Это отдельный этап после стабилизации синхронизации.

## Сборка

Основной вариант:

```text
PySide6 → pyside6-deploy → GeoKZ.exe
```

Резервный вариант:

```text
PySide6 → PyInstaller → dist/GeoKZ/GeoKZ.exe
```

Для первой стабильной версии предпочтительна папочная сборка, а не один огромный
`onefile`: она быстрее запускается, проще диагностируется и обновляется.

## Установщик

Поддерживаемые варианты:

- Inno Setup — простой классический установщик `.exe`;
- MSIX — управляемая корпоративная установка и обновление.

В `packaging/windows/GeoKZ.iss.example` находится заготовка для будущей сборки.

## Что нельзя делать

- заставлять обычного пользователя запускать Docker Desktop;
- хранить пароль БД открытым в интерфейсе;
- открывать локальный PostgreSQL во внешнюю сеть;
- смешивать UI и модели SQLAlchemy в одном слое;
- привязывать бизнес-логику только к Windows.
