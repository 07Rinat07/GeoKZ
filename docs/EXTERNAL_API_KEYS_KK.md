# GeoKZ — сыртқы дереккөздердің API кілттерін алу және баптау (KK)

Өзектілігі: 2026-09-04.

## 1. GeoKZ үшін API кілті не үшін қажет

GeoKZ сыртқы API-сыз да жергілікті дерекқормен толық жұмыс істей алады. API кілті тек бағдарламалық қолжетімділік үшін авторизация талап ететін сыртқы дереккөздерге қажет.

Қазақстан Республикасының `data.egov.kz` ашық деректер порталында кілт REST API v4 арқылы GeoKZ-ке қосылған ашық деректер жиындарын синхрондау үшін пайдаланылады.

GeoKZ нақты API кілтін Git, README, бастапқы код, issue, pull request, скриншот немесе пайдаланушы құжаттамасында сақтамауы тиіс.

## 2. data.egov.kz кілтін қайдан алуға болады

1. Қазақстан Республикасының ресми ашық деректер порталын ашыңыз: `https://data.egov.kz/`.
2. eGov жүйесінде қолжетімді авторизация тәсілімен кіріңіз.
3. **«Әзірлеушілерге» / «Разработчикам»** бөлімін ашыңыз.
4. **«Әзірлеуші кабинеті» / «Кабинет разработчика»** бөліміне өтіңіз.
5. API access / API key бөлімінен жеке әзірлеуші кілтін жасаңыз немесе көшіріңіз.
6. Кілтті құпиясөз менеджерінде немесе GeoKZ жергілікті `.env` файлында сақтаңыз.

Мемлекеттік портал интерфейсі уақыт өте өзгеруі мүмкін. Кілт беру бөлімі басқа жерге ауысса, «Әзірлеушілерге» бөлімін, портал анықтамасын немесе ресми eGov/Open Data қолдауын пайдаланыңыз.

## 3. Кілтті GeoKZ ішіне қайда енгізу керек

Жоба түбірінде үлгі бойынша жергілікті `.env` жасаңыз:

```powershell
Copy-Item .env.example .env
```

`.env` файлын ашып, жергілікті мәнді толтырыңыз:

```env
GEOKZ_EGOV_API_KEY=СІЗДІҢ_НАҚТЫ_КІЛТІҢІЗ
```

Егер кілттің өзінде тырнақша болмаса, қосымша тырнақша қоспаңыз.

`.env` өзгергеннен кейін GeoKZ API немесе Docker Compose қайта іске қосылуы керек.

## 4. Кілтпен не істеуге болмайды

- `.env` файлын Git-ке commit жасамау;
- кілтті `README.md` ішіне жазбау;
- кілтті Python-кодқа тікелей енгізбеу;
- issue/PR ішінде жарияламау;
- чатқа немесе хатқа себепсіз жібермеу;
- скриншотта көрсетпеу;
- кілт жария болып кетсе, әзірлеуші кабинетінде оны ауыстыру/қайтарып алу.

Репозиторийде тек қауіпсіз бос үлгі қалуы тиіс:

```env
GEOKZ_EGOV_API_KEY=
```

## 5. GeoKZ баптауын тексеру

API іске қосылғаннан кейін Swagger ашыңыз:

`http://localhost:8000/docs`

Ресми деректер каталогын тексеріңіз:

```text
GET /api/v1/integrations/kazakhstan/catalog
```

`api_key_configured=true` GeoKZ конфигурациясында бос емес кілт бар екенін білдіреді. Бұл портал кілтті қабылдады дегенді әлі білдірмейді.

## 6. Ресми қазақстандық деректер жиындарын тіркеу

Swagger ішінде орындаңыз:

```text
POST /api/v1/integrations/kazakhstan/register
```

GeoKZ белгілі ресми дереккөздерді сыртқы дереккөздер кестесіне тіркейді. Бұл әрекет тексерілген геологиялық master data-ны өзгертпейді.

## 7. Алғашқы қауіпсіз синхрондау тесті

Мұнай-газ кен орындарының тізімі үшін:

```text
POST /api/v1/integrations/kazakhstan/kz-egov-oil-gas-fields/sync
```

Жер қойнауын геологиялық зерттеу лицензиялары үшін:

```text
POST /api/v1/integrations/kazakhstan/kz-egov-geological-study-licenses/sync
```

Алынған жазбалар алдымен RAW/staging қабатында сақталады:

```text
data.egov.kz
  → RAW
  → checksum/diff
  → normalization
  → matching
  → review
  → verified GeoKZ master data
```

Сыртқы API GeoKZ-тің расталған деректерін автоматты түрде қайта жазбауы тиіс.

## 8. Синхрондау жұмыс істемесе

Келесі ретпен тексеріңіз:

1. `.env` бар ма;
2. `GEOKZ_EGOV_API_KEY` берілген бе;
3. `.env` өзгергеннен кейін қолданба қайта іске қосылды ма;
4. `/api/v1/integrations/kazakhstan/catalog` `api_key_configured=true` көрсете ме;
5. сіздің желіден `https://data.egov.kz/` қолжетімді ме;
6. әзірлеуші кабинетінде кілт жарамды ма;
7. портал нақты dataset нұсқасын/схемасын өзгерткен жоқ па.

GeoKZ типтік жауаптары:

- HTTP `503` — жергілікті API кілті/connector жоқ немесе дұрыс бапталмаған;
- HTTP `502` — сыртқы портал қате жауап берді немесе күтпеген протокол қайтарды;
- HTTP `404` — GeoKZ белгісіз dataset кодын алды.

## 9. GeoKZ-тегі ағымдағы ресми жиындар

`v0.2-dev` кезеңінде:

- `kz-egov-oil-gas-fields` — Қазақстан Республикасының мұнай-газ кен орындары;
- `kz-egov-geological-study-licenses` — жер қойнауын геологиялық зерттеу лицензиялары.

Жаңа ресми ашық дереккөздер тексерілген сайын тізім кеңейтіледі.

## 10. Басқа API кілттері

Болашақ интеграциялар үшін бірдей қағида қолданылады:

```text
пайдаланушы/ұйым құпиясы
  → environment/.env немесе жүйелік secret storage
  → Settings
  → Connector
```

API кілттері геологиялық домен моделінің бөлігі болмауы тиіс.
